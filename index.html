A NOTE FROM FIELDNOTE

How it works

The local Python server reads the file and calculates results. Your rows stay in memory on this machine for the server session. AI wording help is optional: when enabled, only your question and column names are sent to the configured model; data rows stay local.

Fieldnote can calculate totals, averages, medians, counts, comparisons, trends, and relationships. Each answer includes its method and the rows used. If the question is unclear, it asks you to be more specific.

Stop the server to clear uploaded files from memory. Recent questions are saved in this browser only.
